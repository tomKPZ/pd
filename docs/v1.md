# v1: as-built reference

This describes the code at commit `ecb0d7f` (branch `main`). It's what deployed installs run. v2
replaces most of it ([design.md](design.md)). Keep this document accurate until every v1 install has
been migrated ([migration.md](migration.md)).

## Files

| File | Role |
|---|---|
| `pd.py` | Everything at build/setup time: config constants, disk setup, OS installers, UKI build, QEMU test mode. Must run as root. |
| `early.sh` | Stage 1, inside the UKI's initrd: password → Argon2 → find the plain volume → run `late.sh`. |
| `dracut-emergency` | Replaces dracut's emergency shell: runs `/early.sh`, then `/bin/bash`, then `poweroff -f`. |
| `late.sh` | Stage 2, copied into each plain volume: system menu → LUKS → LVM → kexec. Identical to `plain-decoy/late.sh`. |
| `systems/{arch,nixos}/extra.sh` | Per-system hooks copied into the plain volume. `nixos/extra.sh` is the generation menu (formerly `menu.sh`). |
| `detect_shift.c`, `Makefile` | Static helper (built with `musl-gcc`): exit 0 if any input device reports Shift held. |
| `encrypt_install.sh`, `encrypt_hook.sh` | Arch mkinitcpio hook `mycrypt`, installed into the target OS. |
| `configuration.nix`, `hardware-configuration.nix` | Template NixOS config for `install_nixos`. Uses the deprecated `boot.initrd.preLVMCommands`. |
| `patches/0001-0002` | Current NixOS unlock hook: a systemd initrd service (`pd-unlock`). Replaces `preLVMCommands`. |
| `plain-decoy/` | Snapshot of the scripts on a deployed decoy plain volume (no keys, header, or tables). |

## Configuration (constants at the top of `pd.py`)

| Constant | Value | Meaning |
|---|---|---|
| `SHRED_DEVICE` | `True` | Fill the disk with random data first |
| `INIT_VOLUMES` | `[False]` | Sides to create: `False` = decoy, `True` = hidden (hidden is commented out at HEAD) |
| `VG_NAME` | `"system"` | VG name on both sides (`plain-decoy/` uses `sysvg`; renamed so test VGs wouldn't collide with a host VG of that name) |
| `CREATE_SWAP`, `SWAP_SIZE` | `True`, 64 MiB | Linear swap LV |
| `ZERO_HEADER` | 1 MiB | Zeroed area at the start of the disk |
| `META_SIZE` | 256 MiB | Size of the reserved plain-volume area at each end of the disk (plain volume = 255 MiB) |
| `CRYPT_*` | aes-xts-plain64, 512-bit, 4 KiB sectors | Cipher for the plain volume and LUKS |
| `PE_SIZE` | 4 MiB | LVM extent size |
| `THIN_CHUNK_SIZE`, `POOL_META_SIZE` | 512 KiB, 128 MiB | Thin pool chunk and metadata size |
| `MOVE_PES` | `False` | Experimental pvmove reshuffle of the pool layout (unused) |
| `REVERSE_CHUNK_SIZE` | 256 MiB | Granularity of the hidden side's reversed mapping |
| `STATIC_SALT`, `SALT` | `True`, a 128-hex-char test salt | Salt baked into the UKI (random if `STATIC_SALT` is false) |
| `HIDDEN_SALT_SUFFIX` | `"a"` | Appended to the salt for the hidden side |
| `ARGON2_*` | t=14, m=2^18 KiB (256 MiB), p=8 | Argon2id parameters; output is 512 bytes |
| `BOOTSTRAP_KERNEL_VERSION` | `6.12.10-zen1-1-zen` | Host kernel used for the UKI |
| `BOOTSTRAP_CMDLINE` | `ro rd.break=pre-mount systemd.unit=rescue.target` | Gets dracut to the emergency hook (found by trial) |
| `INSTALL` | `True` | `True`: real install; `False`: test mode with a loop image + QEMU |
| `INSTALL_OS`, `DEFAULT_OS` | `["arch", "nixos"]`, `"nixos"` | OSes to install; target of `systems/default` |
| `INSTALL_DEVICE` | `""` | Target disk (empty: only build the UKI) |
| `INSTALL_UKI_PATH` | `/mnt/EFI/BOOT/BOOTX64.EFI` | Where the UKI is written (the USB's ESP must be mounted at `/mnt`) |

## Disk layout

`D` = device size rounded down to 1 MiB.

| Region | Range | Contents |
|---|---|---|
| zero header | [0, 1 MiB) | zeros |
| decoy plain volume | [1 MiB, 256 MiB) | plain dm-crypt, btrfs |
| decoy data region | [256 MiB, D) | LUKS2 (detached header), LVM |
| hidden data region | [0, D − 256 MiB), reversed in 256 MiB chunks | LUKS2 (detached header), LVM |
| hidden plain volume | [D − 256 MiB, D − 1 MiB) | plain dm-crypt, btrfs |
| last MiB | [D − 1 MiB, D) | random fill (keeps both plain volumes the same length) |

dm tables, with sectors of 512 bytes and the disk addressed through the symlink `/boot_tmp/disk`:
* USB `table.txt` (plain volume): `0 522240 linear /boot_tmp/disk 2048`
* decoy `table.txt` (data region): `0 <(D−256 MiB)/512> linear /boot_tmp/disk 524288`
* hidden `table.txt`: for each chunk i, `<i·C> <C> linear /boot_tmp/disk <N − (i+1)·C>`, with C = 524288
  and N = (D − 256 MiB)/512.

## Keys

* `argon2 "$(cat /salt.txt)" -id -t 14 -m 18 -p 8 -l 512 -v 13 -r | xxd -r -p` gives `key.bin`,
  512 bytes.
* Bytes 0–63 are the raw key for the plain volume (`cryptsetup --type plain --key-file`).
* Bytes 64–511 are the passphrase (`--keyfile-offset=64`) for a LUKS2 keyslot. The header,
  `header.dat`, lives in the plain volume. It uses `--pbkdf argon2id`, 4 iterations, 32 KiB memory, 1
  thread (the input has already been through Argon2), `--hash sha512`, and a random volume key. The data
  offset is 0, because the header is detached.
* The hidden side uses salt + `a`.

## Plain volume

`mkfs.btrfs --data=dup --csum=blake2 --nodiscard`. Contents:
```
late.sh  detect_shift  table.txt  header.dat
systems/arch/{env.sh,extra.sh}  systems/nixos/{env.sh,extra.sh}  systems/default -> nixos
```
`env.sh` sets `VG`, `LV_ROOT`, `KERNEL`, `INITRD`, `CMDLINE`. For example, the Arch entry in `plain-decoy/`:
`VG=sysvg LV_ROOT=root KERNEL=/boot/arch-kernel INITRD=/boot/arch-initrd CMDLINE='rw root=/dev/sysvg/root rootflags=subvol=@'`.

## Data region

LUKS2 → PV (first extent zeroed) → `vgcreate --physicalextentsize=4MiB`, containing:
* `swap`: linear, 64 MiB, `mkswap`;
* `thinpool`: created with 1 extent, `--poolmetadatasize=128MiB --chunksize=512KiB --discards=nopassdown`,
  then `lvextend -l+100%FREE`. Result: the pool metadata (`tmeta`, `pmspare`) sits near the front, and
  tdata is split into two segments around it;
* thin LVs, each with virtual size = pool size: `data` (ext4, mounted at `/media/data`), `root` (Arch,
  btrfs), `nixroot` (NixOS, btrfs).

The btrfs roots (`--csum=xxhash`) have the subvolumes `@ @boot @home @home_snapshots @nix @snapshots
@var_cache @var_lib_docker @var_log @var_tmp`, mounted `noatime,lazytime,autodefrag,ssd,nodiscard,compress=zstd:12`.

## Setup (`pd.py`, `INSTALL=True`)

1. Build the UKI. `dracut --no-hostonly` with the host kernel:
   * `--install` argon2, bat, cryptsetup, dmeventd, efibootmgr, fzf, jq, kexec, lsblk, mount, vim;
   * `--add` busybox, debug, rescue;
   * `--omit` network/nfs/cifs/plymouth/…;
   * `--include` a tree holding `dracut-emergency`, `early.sh`, `early_env.sh` (Argon2/cipher args,
     `read_password`), `salt.txt`, and `table.txt`.

   Then `ukify build` writes it to `INSTALL_UKI_PATH`.
2. If `INSTALL_DEVICE` is set:
   * shred: a plain dm-crypt over the whole disk with a random key, filled with zeros. The key is
     **printed at the end**;
   * zero the first MiB;
   * for each side in `INIT_VOLUMES`: password → Argon2 → plain volume → LUKS → LVM → filesystems →
     `install_arch`/`install_nixos`.
3. Print the salt and the hidden-boot commands.

`install_arch`: `pacstrap` base, btrfs-progs, linux, linux-firmware, lvm2; writes fstab; installs the
`mycrypt` hook with `HOOKS=(base udev autodetect microcode modconf kms keyboard keymap consolefont block
mycrypt lvm2 filesystems fsck)` and `MODULES=(btrfs ata_piix)`; creates the `/boot/arch-{kernel,initrd}`
symlinks; prompts for the root password.

`install_nixos`: copies `configuration.nix` and `hardware-configuration.nix`, generates
`filesystems.nix`, and runs `~/.nix-profile/bin/nixos-install` with `nixpkgs=channel:nixos-24.11`.

## Boot

1. The UKI boots dracut, which stops at `rd.break=pre-mount` and runs `dracut-emergency` → `/early.sh`.
2. `early.sh`:
   * deletes the `BootCurrent` NVRAM entry (`efibootmgr`);
   * reads the password and runs Argon2, writing `/boot_tmp/key.bin`;
   * for each `/dev/disk/by-id/*`: symlink it as `/boot_tmp/disk`, `dmsetup create --readonly dm-plain
     /table.txt`, open plain dm-crypt, mount btrfs `ro`, and run `/mnt/plain/late.sh`;
   * when no disk works: shred the key and fall through to bash.
3. `late.sh`:
   * picks the system: `$LATE`, or the Shift menu, or `default`; sources `env.sh`;
   * `dmsetup create --readonly dm-luks`, opens LUKS with `header.dat` and key offset 64, runs
     `lvm vgchange -ay`, and mounts `@boot` read-only at `/mnt/luks/boot`;
   * sources `extra.sh`. On NixOS this mounts `@nix` at `/nix` and offers the generation menu, which
     sets `KERNEL`, `INITRD`, and `CMDLINE` from the chosen generation;
   * copies and pads the initrd, then appends a cpio of `/boot_tmp`: `key.bin`, `table.txt`,
     `header.dat`, and the `disk` symlink to the by-id path;
   * runs `kexec -l`, shreds, then `kexec -e`.
4. Target hook (Arch `mycrypt`, or NixOS `pd-unlock`): `dmsetup create dm-luks /boot_tmp/table.txt`, open
   LUKS from `/boot_tmp`, shred `/boot_tmp`. The distro then activates LVM and mounts root.

Hidden boot: [booting.md](booting.md#hidden-boot).

## Test mode (`INSTALL=False`)

Creates a `TEST_DISK_SIZE` image, attaches it to a loop device, and runs setup. Then, for each side and
OS, it builds a bootstrap initrd with the hidden edits pre-applied and `LATE` set, and boots it in QEMU
using the host kernel (`console=ttyS0`). Needs root.

## Known issues

From the v2 design review; fixed in v2.
* The shred key is printed to stdout (anyone with it can see every region written since setup).
* Key material goes into `tempfile.mktemp()` files and is removed with `rm`, not shredded.
* The default salt is static.
* Bootstrap btrfs mounts lack `rescue=nologreplay`. LVs are activated read-write on top of the read-only
  crypt device, so whether a dirty log makes the boot fail or gets replayed through it depends on the
  kernel.
* Test mode passes `LATE` as a full path, but `late.sh` expects a system name.
* `reversed_table()` ignores `start` when `start != 0`. Latent: it's always called with 0.
* The hidden data region covers the decoy's plain volume.
* `configuration.nix` uses the deprecated `preLVMCommands` (the replacement is the unit in
  `patches/`), and `install_nixos` hardcodes `nixos-24.11` and a `~/.nix-profile` path.
* The decoy's LVM metadata history records pd's unusual commands and device names.
* `POOL_META_SIZE` is fixed rather than computed from the disk size.
